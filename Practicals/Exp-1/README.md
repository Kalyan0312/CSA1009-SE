# Experiment 1 – Kanban Board

## Aim
To create a Kanban Board to visualize software development tasks and simulate their workflow.

## Tool Used
Trello

## Board Columns
- To Do
- In Progress
- Done

## Sample Tasks
1. Collect Requirements
2. Design Database
3. Create Login Module
4. Develop Patient Registration
5. Develop Appointment Module

## Workflow Demonstration
- **Done:** Collect Requirements
- **In Progress:** Design Database
- **To Do:** Create Login Module, Develop Patient Registration, Develop Appointment Module

## Result
A Kanban board was created with sample tasks and the tasks were moved across the columns to simulate the software development workflow.
